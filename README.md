# 色准 / ColorSpec 产品图片潘通色卡工作台

这是一个以“自动抓主要颜色”为主流程的图片取色与潘通候选匹配 MVP：

- 上传 JPG / PNG / WEBP 产品图片
- 一键自动抓取主要色、辅助色、点缀色
- 按颜色面积从大到小显示占比
- 自动跳过近白背景、极暗像素和部分高光
- 为每个主要颜色返回潘通前三候选、ΔE00 和置信度
- 点击结果卡可查看候选详情；点击图片可做局部复核
- 支持 Solid Coated（C）和 Solid Uncoated（U）
- 高级设置默认收起，避免干扰主流程
- 支持保存到浏览器本地和导出主要颜色 JSON

## 启动

在本目录执行：

```bash
python3 -m http.server 8765
```

然后打开：`http://127.0.0.1:8765/`

不要直接双击 `index.html`，因为浏览器会阻止本地 `palette.json` 的读取。

## 当前边界

当前网页使用本项目已有的本地导入 C/U 候选库用于演示。正式生产版本应接入潘通官方授权数字色库/API，并保留实体色卡或供应商样品确认环节。网页输出是候选参考色，不是自动生产放行色号。
